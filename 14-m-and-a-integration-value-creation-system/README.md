# M&A Integration & Value Creation System

### A practical executive system for evaluating acquisitions, validating the deal thesis, integrating businesses, and converting transaction assumptions into measurable enterprise value.

An acquisition does not create value when the transaction closes.

Closing transfers ownership.

Value is created when the combined business produces better economic outcomes than the businesses could have produced independently.

Leadership must connect:

**Strategic Rationale → Deal Thesis → Due Diligence → Value Drivers → Integration Design → Day 1 → Execution → Synergies → Performance → Value Realization**

The executive questions are:

1. Why are we buying this business?
2. What value do we believe the transaction can create?
3. Which assumptions must be true?
4. What could destroy the investment thesis?
5. What must be validated before closing?
6. What must change after closing?
7. What must not change?
8. Which synergies are real?
9. Who owns each source of value?
10. How quickly should value appear?
11. What integration risks could damage the underlying business?
12. How will leadership know whether the acquisition is creating the value originally underwritten?

> **The deal thesis should become the integration agenda.**

# The M&A Value Creation Logic

The operating logic is:

**Strategy → Target → Deal Thesis → Diligence → Valuation → Integration Thesis → Day 1 → 100-Day Plan → Synergy Execution → Operating Model → Performance → Value Realization**

The objective is not integration for its own sake.

The objective is value creation.

Potential value sources include:

- Revenue growth
- Cross-sell
- Customer expansion
- Geographic expansion
- Pricing
- Product expansion
- Distribution
- Cost synergies
- Procurement
- Shared services
- Technology consolidation
- Productivity
- Talent
- Intellectual property
- Data
- Market position
- Multiple expansion

Every material value source should have:

- A hypothesis
- A baseline
- An owner
- A target
- A deadline
- A measurement method

# 14. Define the Integration Thesis

Determine the required degree of integration.

Possible models:

### Preserve

Keep the target largely independent.

Useful when autonomy is part of the value.

### Coordinate

Share selected capabilities while maintaining significant independence.

### Integrate

Combine major functions, systems, and operations.

### Absorb

Fully incorporate the target into the acquiring organization.

# 21. Distinguish Gross Synergy From Net Value

A $5 million cost synergy does not necessarily create $5 million of value.

Calculate:

**Net Synergy = Gross Synergy - Implementation Cost - Dis-synergies - Ongoing Incremental Cost**

Use:

| Synergy | Gross Value | Implementation Cost | Dis-synergy | Net Value |
|---|---:|---:|---:|---:|
| | | | | |

Measure net economics.

Not headline synergy.

# 34. Know When Integration Is Complete

Integration should not remain a permanent program.

Integration is approaching completion when:

- Critical systems are operating as intended
- Leadership roles are stable
- Decision rights are clear
- Required processes are integrated
- Synergies are embedded in normal operations
- Value creation is managed through standard business reviews
- Integration risks have materially declined

Use:

| Completion Criterion | Status | Evidence | Remaining Action |
|---|---|---|---|
| | | | |

Then transfer remaining responsibilities into the normal operating model.

The business should eventually stop being managed as an acquisition.

Before approving a transaction, leadership should be able to answer:

**Why this target?**

**Why buy rather than build or partner?**

**What exactly creates value?**

**What evidence supports those assumptions?**

**How reliable is the revenue?**

**What is customer concentration?**

**What is retention?**

**Can the commercial engine scale?**

**Which leaders are critical?**

**What integration risks could destroy value?**

**What should be integrated?**

**What should be preserved?**

**What are the real net synergies?**

**What is the downside?**

**Who will own value creation after closing?**

If these questions cannot be answered, the investment thesis requires further work.

# Executive Standard

After closing, leadership should always know:

**Is the underlying business still healthy?**

**Are customers being protected?**

**Are critical people staying?**

**Is the integration progressing?**

**Are synergies actually being realized?**

**What is the net value after integration costs?**

**Where is value leaking?**

**Which deal assumptions have changed?**

**What does the current forecast imply?**

**Does the original investment thesis remain valid?**

**What requires intervention?**

**Who owns each source of value?**

If leadership cannot answer these questions, the acquisition is being integrated without being economically managed.

# Operating Principle

> **Start with the investment thesis.**
>
> **Diligence the assumptions that matter.**
>
> **Protect the business you acquired.**
>
> **Preserve what created the value.**
>
> **Integrate only where integration creates value or controls risk.**
>
> **Assign every synergy an owner.**
>
> **Measure net value, not headline synergy.**
>
> **Reconcile the deal model with operating reality.**
>
> **Intervene when value leaks.**
>
> **Move integration into normal operations when the work is complete.**

Closing the transaction is a milestone.

The executive responsibility begins with turning the investment thesis into operating performance and measurable enterprise value.
